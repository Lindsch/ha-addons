# Lindsch's Home Assistant add-ons

Personal Home Assistant add-ons, shared as-is in case they're useful to someone else.

## Add-ons

| Add-on | Description |
| --- | --- |
| [Wiezer](wiezer) | Freezer inventory by drawer: what's in which drawer, how much, and since when. |

## Installation

1. In Home Assistant, go to **Settings → Add-ons → Add-on Store**.
2. Open the menu (⋮) at the top right, choose **Repositories**, and add:
   `https://github.com/Lindsch/ha-addons`
3. Find the add-on in the store and install it.
