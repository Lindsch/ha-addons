# Wiezer

*/ˈwiːzər/ — rhymes with "freezer"*

A small Home Assistant add-on to keep track of what's in which freezer drawer.

> **Personal project:** Wiezer was built for my own household and is shared as-is in
> case it's useful to someone else. The code was written largely by Claude
> (Anthropic's AI assistant) under my direction. It's tested on my own setup only —
> no guarantees, no support.

## Features

- See at a glance what's in which drawer, how much, and since when.
- Add food quickly: suggestions from earlier entries fill in unit, amount and drawer;
  today's date is filled in automatically.
- Take out part or all of an entry with digit wheels, plus/minus buttons, or by typing.
- Move entries between drawers, whole or in part, from the details or by drag and drop,
  with undo.
- Copy the label text (name, amount, date) to paste into a label printer app.
- Drawers, optional drawer groups (e.g. a second freezer) and units are configurable.
- Several people can use it at the same time; changes show up within seconds.
- English and German, light and dark theme, chosen per person.

It opens in the Home Assistant sidebar and uses your normal Home Assistant login, so
it also works in the companion app and remotely.
